# Scored eager SAT scaling beyond 6,282 states

Native GitHub Actions: https://github.com/liyong31/DFAMiner/actions/runs/38538499461
Date: 14 October 2026. Repository: liyong31/DFAMiner; base cegar 209f97e.
Each configuration has a 60-second process timeout. PySAT CaDiCaL 1.9.5,
9,600 or 19,200 deterministic labelled binary samples generated by the
same six-state modular counter family. Target size k=5 is UNSAT.

The figures below are **single end-to-end measurements**, including
input 3DFA construction, cheap witness collection, eager CNF and SAT.

| 3DFA states | Method | Preprocessing | Clauses | Conflicts | Total |
|---:|---|---:|---:|---:|---:|
| 10,107 | Ordered eager | 0 | 2,510,010 | 26,780 | 15.45685 s |
| 10,107 | Cheap lower bound only | 0.02355 s | 2,510,010 | 26,780 | 15.25299 s |
| 10,107 | Impact 300 | 0.03529 s | 2,511,510 | 23,392 | 13.58369 s |
| 10,107 | Short 300 | 0.03514 s | 2,511,510 | 15,238 | 11.38636 s |
| 10,107 | Degree 300 | 0.03476 s | 2,511,510 | 16,426 | 11.72306 s |
| 16,122 | Ordered eager | 0 | 16,031,420 | 6,908 | **29.54646 s** |
| 16,122 | Cheap lower bound only | 0.03531 s | 16,031,420 | 6,908 | 29.23720 s |
| 16,122 | Impact 300 | 0.04643 s | 16,032,920 | 7,742 | 30.97450 s |
| 16,122 | Short 300 | 0.04609 s | 16,032,920 | 6,764 | 30.12256 s |
| 16,122 | Degree 300 | 0.04713 s | 16,032,920 | 7,823 | 31.43271 s |

All methods returned UNSAT, agreeing on exact satisfiability.

Conclusion: Score-based lemmas survive at approximately 10k states:
short-witness 300 gives 15.46 / 11.39 = **1.36x** improvement with 1,500
extra pair-clauses. At 16k states the improvement does not persist; the
baseline is fastest among tested scored modes.

The 16,122-state case has about 16 million CNF clauses versus 2.51
million for the 10,107-state case. This is mostly due to the explicit
positive/reject source-state pair clauses, whose size is O(|F||R|k).
This is a more immediate scaling bottleneck than the 30-50ms light
incompatibility preprocessing. HOWEVER, prior experiments showed
that removing these implied clauses can weaken propagation; do not drop
them wholesale without testing selective retention, compressed encodings,
or CNF structure/order variants.

Next experiments should repeat each configuration and include SAT at
k=6, not only UNSAT at k=5, before choosing a default scoring policy.
